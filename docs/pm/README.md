# Project Management Workspace

This directory (`docs/pm/`) is the dedicated workspace for the **Project Manager** of `itemseed`.

## Role & Responsibilities

In accordance with [AGENTS.md](../../AGENTS.md), the Project Manager is responsible for:
- Requirements definition and scoping.
- Task breakdown and milestone planning.
- Documentation management across `docs/`, `README.md`, `AGENTS.md`, and `FRONTEND_KANBAN.md`.
- Managing the task Kanban board:
  - Exclusive authority to publish tasks into `TODO`.
  - Transitioning tasks from `Doing` to `Done` or `Pending`.
  - Prohibited from directly modifying application source code (`*.js`, `*.html`, `*.css`).

## Directory Structure

- `README.md`: Overview and guidelines for the Project Management workspace.
- `requirements/`: Feature specifications, scope definitions, and user story documents.
- `milestones/`: Milestone plans, sprint reviews, and progress tracking reports.
- `templates/`: Standardized templates for task breakdown, acceptance criteria, and release notes.

## Workflow Integration

- **Task Board**: All active tasks are tracked in [FRONTEND_KANBAN.md](../../FRONTEND_KANBAN.md).
- **Governance**: Refer to [AGENTS.md](../../AGENTS.md) for role boundaries and cross-role interaction protocols.
