# Project Manager Workspace Policies

This directory (`docs/pm/`) is the exclusive workspace reserved for the **Project Manager** role (and Super Admin).

## Access & Modification Restrictions

- **Authorized Roles**:
  - **Project Manager**: Full read, write, and administrative access to all files within `docs/pm/`.
  - **Super Admin**: Full access.
- **Prohibited Roles**:
  - **Frontend Developer**: Strictly prohibited from creating, editing, or deleting any files or directories in `docs/pm/`.

## Directory Purpose

This workspace is maintained by the Project Manager for:
- Product and feature requirements (`requirements/`).
- Milestone schedules and status tracking (`milestones/`).
- Management templates and task specifications (`templates/`).
