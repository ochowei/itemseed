# [TASK-014] Generated Assets Licensing & Documentation (CC0 1.0)

## 1. Overview & Objective
Explicitly define and document the legal licensing terms for all procedural output generated by ItemSeed (exported PNG files and JSON specifications). The objective is to release all generated assets into the public domain under the Creative Commons CC0 1.0 Universal Public Domain Dedication, removing any legal ambiguity or hesitation for game developers utilizing ItemSeed in commercial or indie projects.

## 2. Problem Statement
Many procedural generator tools fail to separate the license of the generator engine (the code) from the license of the resulting artwork (the generated assets). If a game developer generates an icon using ItemSeed, they risk potential intellectual property disputes or downstream licensing conflicts unless the generator's authors explicitly grant unconditional public domain rights. Furthermore, ambiguous statements like "free for non-commercial use only" or contradictory terms like "CC0 but you cannot resell" invalidate legal protection and deter game creators.

## 3. Scope & Requirements

### 3.1 Adopt CC0 1.0 Universal Public Domain Dedication
- Apply CC0 1.0 strictly to all user-generated artifacts produced by ItemSeed:
  - Downloaded 16×16 and 32×32 transparent PNG icons.
  - Exported JSON item specifications.
  - Batch composite spritesheets.

### 3.2 Author `ASSET-LICENSE.md`
Create `ASSET-LICENSE.md` in the repository root directory containing:
1. Full legal text of the Creative Commons CC0 1.0 Universal Public Domain Dedication.
2. Plain-English summary specifying:
   - **Personal Projects**: Permitted without restriction.
   - **Commercial Games**: Permitted without restriction.
   - **Modification**: Free to edit, recolor, upscale, crop, or remix.
   - **Attribution**: Optional (appreciated, but never legally required).
   - **No Contradictory Clauses**: Explicit declaration that no conflicting anti-resale or non-commercial restrictions apply to generated assets.

### 3.3 Synchronize Project Documentation
- **`README.md`**: Add a dedicated "Generated Assets License" section explaining CC0 1.0 terms and linking to `ASSET-LICENSE.md`.
- **itch.io Store Copy**: Prepare the exact licensing description block ready for pasting into the itch.io project dashboard.

## 4. Acceptance Criteria
- [x] Root `ASSET-LICENSE.md` created with CC0 1.0 legal text and plain-English usage guide.
- [x] Plain-English guide explicitly permits personal and commercial game use, modifications, and confirms attribution is non-mandatory.
- [x] No conflicting clauses (e.g., "no resale", "non-commercial only") exist in asset licensing terms.
- [x] `README.md` contains a clear "Generated Assets License" section linking to `ASSET-LICENSE.md`.
- [x] itch.io release licensing text prepared in docs for distribution.
