# Bow Generator Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement a seeded, procedural bow and arrow generator (`drawBow`) supporting 3 distinct stave archetypes, dedicated wood and fletching palettes, diagonal 45° nocked arrow composition, and dual native resolutions (32×32 and 16×16).

**Architecture:** Two-phase spec-render architecture: `sampleBowSpec(rng)` centralizes deterministic random number generation and returns a plain spec object; `renderBowSpec32` and `renderBowSpec16` are pure rendering functions drawing integer-aligned canvas pixels with continuous dark outlines.

**Tech Stack:** Vanilla JavaScript (ES6+), HTML5 Canvas 2D context, Node.js validation scripts (`check-i18n`, `check-batch`, `snapshot-regression`), zero build tools.

**Spec Reference:** [`docs/superpowers/specs/2026-09-21-bow-generator-design.md`](../specs/2026-09-21-bow-generator-design.md)

## Hard Constraints
- **Zero sub-pixel anti-aliasing**: All coordinates, widths, and heights must be strictly integers (`Math.floor` / `Math.round`).
- **Continuous outline**: Dark outline (`outline` color) must be solid with no 1-cell diagonal leaks or floating disconnected pixels.
- **Pure render functions**: Zero RNG calls inside `renderBowSpec32` or `renderBowSpec16`. The same spec must produce identical pixels every time.
- **Naming hygiene**: Prefix module-internal constants with `BOW_` to prevent collisions with `sword.js`, `spear.js`, `shield.js`, or `staff.js`.

```javascript
const FLETCHING_COLORS = {
  crimson: { main: '#dc2626', shadow: '#991b1b' },
  emerald: { main: '#16a34a', shadow: '#166534' },
  azure:   { main: '#2563eb', shadow: '#1e40af' },
  white:   { main: '#f1f5f9', shadow: '#94a3b8' },
};

const FLETCHING_NAMES = ['crimson', 'emerald', 'azure', 'white'];

function sampleBowPalette(rng) {
  const woodFamily = rng.pick(BOW_WOOD_NAMES);
  const woodPalette = BOW_WOOD_FAMILIES[woodFamily];
  const { family: metalFamily, palette: metalPalette } = sampleSwordPalette(rng);
  const fletchingName = rng.pick(FLETCHING_NAMES);
  const fletchingPalette = FLETCHING_COLORS[fletchingName];

  return {
    woodFamily,
    woodPalette,
    metalFamily,
    metalPalette,
    fletchingName,
    fletchingPalette,
  };
}
```

## Task 2: Implement Core Bow Generator (`bow.js`) — Spec Sampling & 32×32 Native Rasterizer

**Files:**
- Create: `bow.js`

- [ ] **Step 1: Write `sampleBowSpec(rng)` and `renderBowSpec32(ctx, spec)` in `bow.js`**

Implement `bow.js` with:
1. `BOW_ARCHETYPES = ['longbow', 'recurve', 'shortbow']` with weighted distribution `[3, 2, 1.5]`.
2. `sampleBowSpec(rng)`:
   - Sample archetype from `BOW_ARCHETYPES`.
   - Sample palette from `sampleBowPalette(rng)`.
   - Sample `hasGripWrap = rng.chance(0.6)`.
   - Sample `hasNockReinforcement = archetype === 'longbow' ? true : rng.chance(0.5)`.
   - Sample `arrowShaftWood = WOOD_PALETTE`.
3. `renderBowSpec32(ctx, spec)`:
   - **Layer 1: Bowstring**: Drawn from upper nock to nocking point `(10, 21)` to lower nock. High contrast string color (`#e2e8f0` with dark shadow).
   - **Layer 2: Bow Stave (Upper & Lower Limbs)**:
     - Limbs rendered at 45° angle with integer Bresenham / table coordinates.
     - Outlines in `spec.woodPalette.outline`.
     - Body in `spec.woodPalette.main`, highlight on upper face in `spec.woodPalette.shine`, shadow on inner face in `spec.woodPalette.shadow`.
     - Grip wrap centered at `(16, 16)` using `LEATHER_PALETTE`.
     - Nock reinforcements at tips using `spec.metalPalette`.
   - **Layer 3: Arrow**:
     - Shaft: Diagonal 1px integer line from `(6, 25)` to `(24, 7)`.
     - Fletching: 2 angled vanes at `(6, 25)` .. `(8, 27)` colored with `spec.fletchingPalette`.
     - Arrowhead: 3×3 faceted diamond point centered around `(25, 6)` using `spec.metalPalette`.
4. `drawBow(ctx, rng, size)` convenience entry.

- [ ] **Step 1: Implement `renderBowSpec16(ctx, spec)` in `bow.js`**

Add native 16×16 rendering logic to `bow.js`:

- Arrowhead: 2×2 diamond point at `(12, 3)` .. `(13, 2)`.
- Fletching: 2px offset barb at `(3, 12)` in `spec.fletchingPalette.main`.
